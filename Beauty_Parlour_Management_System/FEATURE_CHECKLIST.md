# Complete update checklist

| Feature | Where to use it |
|---|---|
| Register / username, email or phone login | Register / Login |
| Edit profile | Profile → Edit profile |
| Forgot password | Login → Forgot password |
| Multiple services per booking | Book → Additional services |
| Packages / discounted offers | Packages; manager → Create package |
| Available slots / overlap protection | Book |
| Customer cancellation and rescheduling | Profile |
| Working days, skills, hours and whole-day leave | Staff |
| Beautician login / restricted access | Staff → Create beautician login |
| Custom manager overview | Dashboard |
| Day/week calendar and staff filter | Calendar |
| Walk-in and customer reception bookings | Walk-in / Customers → Book |
| Customer search and appointment history | Customers |
| No-show status | Dashboard → Status |
| Staff breaks / salon holidays | Breaks & holidays |
| Waiting list and slot offers | Customer Waiting list / manager Waiting list |
| Service management | Services in manager navigation |
| Bills, discounts, print/PDF | Completed appointment → Create bill |
| Cash / UPI / card and partial payment records | Bill → Record payment |
| Corrections and refunds with reasons | Bill → Correct / refund |
| Monthly reports and charts / CSV / print/PDF | Reports |
| Product inventory and low-stock indicators | Inventory |
| Stock usage/deliveries with history | Inventory → Receive / use |
| In-app updates and read status | Updates |
| Email notifications | SMTP setup + notification worker |
| Appointment reminders | Reminder command + hourly worker |
| Customer ratings/reviews | Completed appointment → Review treatment |
| Contact messages | Contact / manager Messages |
| Salon contact, hours and booking policies | Settings |
| Activity history | Activity |
| Database/media backups | Superuser Backup / BACKUP_WINDOWS.bat |
| Validated restore with recovery backup | restore_parlour command |
| Easier Windows launch | SETUP_WINDOWS / START_WINDOWS |

No actual online charges/refunds, tax engine or inventory auto-consumption is included. Payment/refund forms record transactions already performed. Email delivery requires your provider settings; scheduled processing requires a running computer/worker. These boundaries are described in README.md.
