Restore a backup

Restoring replaces current data. Stop the server first, then run the command below from the project folder. A recovery copy is created automatically before replacement.

.venv\Scripts\python.exe manage.py restore_parlour "C:\path\backup.zip" --confirm-restore
.venv\Scripts\python.exe manage.py migrate

Use only backups made by this project. Restart the server after migration.
